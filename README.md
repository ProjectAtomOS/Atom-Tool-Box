# Atom ToolBox

A lightweight, free, and open-source system optimization utility built for gamers, power users, and developers. Atom ToolBox provides a clean, automated interface to safely streamline Windows, reduce system latency, and eliminate background bloatware with a single click.

---

## Features & Capabilities

### Windows & Visual Optimizations
* Telemetry & Data Collection: Disables native diagnostic tracking and background data collection seamlessly.
* System Privacy: Strips native Cortana, Action Center notifications, and cloud sync settings to keep your OS isolated.
* Power & Performance: Force-activates the hidden Ultimate Performance power scheme while disabling sleep/hibernation power drops.

### High-Refresh-Rate Gaming Enhancements
* Advanced MMCSS & Priority Tuning: Injects high-priority scheduling for essential foreground apps and network processing.
* DPC Latency Reduction: Globally disables network throttling and interrupt moderation to optimize online response times.
* GPU & Hardware Acceleration: Fine-tunes hardware scheduling and adjusts graphics stack thresholds (TdrDelay) for peak FPS stability.

### Safe Bloatware & Component Control
* Universal AppX Removal: Easily clean up pre-installed background bloatware (Xbox overlays, cloud components, and telemetry packages) without breaking essential system files.
* Service Management: Disables over 130 non-essential background services while carefully preserving mandatory dependencies like the NVIDIA Control Panel container.
* Revert Support: Features integrated, robust rollback scripts to let you restore core functionalities like Windows Search, Bluetooth, or Printer services instantly if needed.

## 100% Open Source & Community Driven

The custom Windows optimization space is often filled with closed-source executables that trigger security flags. Atom ToolBox is completely open-source.

* Complete Transparency: Every registry tweak, service state modification, and component change is fully audit-ready in the repository.
* Zero Hidden Paywalls: Built with the core vision of giving power back to users without gatekeeping features.

## Getting Started

### Installation
1. Go to the Releases tab on the right side of this repository.
2. Download the latest compiled setup installer (AtomToolBox-Setup-0.1.5.exe).
3. Run the installer as an Administrator to give the app full clearance to apply system changes safely.
