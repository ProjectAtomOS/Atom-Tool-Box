# AtomToolBox 0.2.0

Windows 10/11 x64 tweak and system utility toolbox.

## Installer

- File: `AtomToolBox-Setup-0.2.0.exe`
- Size: 76,645,319 bytes
- SHA-256: `4B3FCC840674C410796E3538C1C68B48C70FE71EBB48831D462A55E13F383FF7`

## Highlights

- Background Monitor with process kill and application blocking
- Startup Manager and Context Menu tools
- Personalize, Cleaner, Brave Debloater and App Installer
- Power Plans, everyday power settings and timer resolution controls
- Backup & Restore for restore points and registry backups
- Global search, live CHECK STATE and registry audit export
- Dark, OLED and Light themes

## Upgrade notes

This release replaces the 0.1.5 source tree and removes build output from version control. Install over the previous version with the new setup executable.

The four ADVANCED entries are intentionally locked and open the Atom Optimizer PRO prompt.

## Known notes

- The installer is not code-signed yet, so Windows SmartScreen may show a warning.
- Windows 10 22H2 was the primary live-test platform for this release.
